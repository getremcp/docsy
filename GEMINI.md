# Docsy — source-linked developer documentation

Use the Docsy remote MCP tools when you need current or version-specific
documentation for an SDK, framework or library. Resolve the official library,
choose the relevant version, and cite original publisher documentation URLs.
Do not confuse a source snippet with a confirmed runtime behavior. Do not send
credentials, secrets, personal information or proprietary source to public
documentation queries. Docsy's public tools are read-only.
